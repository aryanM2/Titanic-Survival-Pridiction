# 🚢 Titanic Survival Prediction

A machine learning classification project that predicts whether a passenger survived the Titanic disaster using different supervised learning algorithms.

## 📌 Project Overview

This project uses the Titanic dataset to train and compare five machine learning models. The goal is to understand how different classification algorithms perform on the same dataset and identify the best-performing model.

## 🤖 Machine Learning Models

* Logistic Regression
* Naive Bayes
* Decision Tree
* Support Vector Machine (SVM)
* K-Nearest Neighbors (KNN)

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## 🔍 Project Workflow

1. Load the Titanic dataset.
2. Perform data cleaning and preprocessing.
3. Handle missing values.
4. Perform exploratory data analysis.
5. Select and engineer relevant features.
6. Split data into training and testing sets.
7. Train five machine learning models.
8. Evaluate and compare model performance.

## 📊 Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Titanic-Survival-Prediction.git
```

Navigate to the project directory:

```bash
cd Titanic-Survival-Prediction
```

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

## ▶️ How to Run

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open `Titanic_Survival_Prediction.ipynb` and run the cells to preprocess the data, train the models, and compare their performance.
